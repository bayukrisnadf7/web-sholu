# Sholu landing page

Landing page ReactJS + Vite untuk aplikasi Sholu. Materi dan aset bersumber dari proyek lokal `SalatBuddy`: panduan gerakan dan bacaan, penyesuaian kemampuan, kiblat, refleksi, dan pendamping Apple Watch.

## Menjalankan

```sh
npm install
npm run dev
```

Buka URL lokal yang ditampilkan Vite.

```sh
npm run build
npm run preview
```

Hasil build ada di `dist/` dan dapat dihosting sebagai situs statis.

## Konten dan interaksi

- Bahasa Indonesia, navigasi responsif, dan menu seluler.
- Ilustrasi gerakan asli dari aset Sholu serta mockup perangkat berbasis CSS. Mockup adalah ilustrasi pengalaman aplikasi, bukan tangkapan layar.
- Preview gerakan Qiyam dan Tasyahud yang dapat diganti.
- Video demo asli dalam dialog dengan kontrol pemutar dan dukungan tombol Escape.
- FAQ menggunakan elemen disclosure native.
- Dukungan keyboard, focus visible, dan preferensi reduced motion.

Tautan App Store/TestFlight belum ditemukan dalam materi proyek, sehingga CTA mengarah ke demo. Tambahkan tautan resmi setelah tersedia. Font DM Sans dan Manrope dimuat dari Google Fonts dengan fallback sans-serif.
