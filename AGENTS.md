# Sholu project guidance

- For coding changes, read and apply `.agents/skills/ponytail/SKILL.md`.
- For interface changes, also read `.agents/skills/impeccable/SKILL.md` and the relevant references. Product constraints are in `PRODUCT.md`; the visual system is in `DESIGN.md`.
- Keep English and Indonesian content in sync, including accessible labels and metadata. Keep the EN/ID control visible in the navbar on mobile.
- Preserve the original app screenshots and demo. Do not invent download links, product features, or endorsements.
- Run `npm run build` after source changes and check changed interactions at desktop and mobile sizes.

- Product copy must be supported by the SalatBuddy implementation/localization or explicit owner-provided material. Read `CONTENT_SOURCES.md` before changing product claims; update the mapping when the source changes. Do not restore generic marketing copy or dummy team members.
